# PROJECT: RECOVERY v0.5.0

Classified visual-data reconstruction puzzle for the Pip-Boy Mk V.

## Flow
1. Three fixed intro puzzle images play in order.
2. After the third intro puzzle, a cinematic HACK SUCCESS / CRITICAL DATA UNLOCKED screen appears.
3. The main archive begins.
4. Every third level becomes a BONUS RECOVERY from the separate 15-image personal/bonus archive.
5. After each recovery, the full image is revealed before continuing.

## Controls
- Left knob rotate: horizontal cursor movement
- Right knob rotate: vertical cursor movement
- Left knob press: select/swap / advance

## Current image pools
- INTRO: 3 supplied terminal/hacking images
- MAIN: existing 12 archive images are temporarily used for regular levels
- BONUS: 15 supplied personal/random images, including the three newest additions

The main archive can be replaced/expanded later without changing the puzzle engine.
